# KOMŞUM

Apartmanda ne oluyor, herkes bilsin. Aidat, kasa, dekont onayı, duyuru, arıza ve evrak takibi için telefona kurulabilen web uygulaması.

- **Arayüz:** React (PWA), `src/`
- **Veritabanı ve kurallar:** Supabase / PostgreSQL, `supabase/schema.sql`
- **Sunucu fonksiyonları:** Vercel, `api/` (ayarlar ve telefon bildirimi gönderimi)

Kurulum adımları için [KURULUM.md](KURULUM.md) dosyasına bak.
